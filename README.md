# ⚡ Sistema de Control y Seguimiento Operativo - Backbone

Plataforma web interna desarrollada en **Streamlit y Python** para la gestión integral de tareas, control de SLA por demoras, ingesta inteligente de planillas y geolocalización de cuadrillas en la red Backbone (Seguridad Física Fnet).

## 🚀 Funcionalidades Principales
- **Ingesta Híbrida y Segura:** Carga masiva mediante Excel con validación de duplicados por número de Ticket.
- **Tratamiento Directo:** Modificación de estados operativos directamente desde la interfaz web.
- **Control de Alertas:** Detección automática de tareas pendientes o en curso con más de 24 horas sin resolución.
- **Mapa Logístico:** Visualización geoespacial interactiva para la optimización de traslados y cercanía de recursos técnicos.
- **Reportes:** Exportación limpia de vistas filtradas en formato Excel (.xlsx).
